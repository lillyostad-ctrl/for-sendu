# حافظه‌ی قایقران (Sendō)

این مخزن **خصوصی** حافظه‌ی شخصی شماست که قایقرانِ اپ **Sendō** (سندو) هنگام گفتگو با شما می‌سازد و هر روز کامل‌تر می‌کند. همه‌چیز متعلق به خودتان است: می‌توانید بخوانید، دانلود کنید یا با Obsidian باز کنید (لینک‌ها `[[...]]` هستند).

| مسیر | محتوا |
|---|---|
| `mind/graph.json` | نسخه‌ی اصلی و ماشینی حافظه: گره‌ها (آدم‌ها، پروژه‌ها، ایده‌ها، هدف‌ها، نگرانی‌ها…) و ارتباط‌ها |
| `mind/core.md` | نمای کلی: شما چه کسی هستید، روال روزانه، آدم‌های مهم، تمرکز فعلی |
| `mind/profile.md` | مدل شخص: ویژگی‌های شخصیت، ارزش‌ها، نقاط قوت، نقش‌ها، چرخ زندگی، سبک زندگی، الگوها و مرحله‌ی تغییر هر عادت — هر مورد با میزان اطمینان |
| `mind/INDEX.md` | فهرست همه‌ی موارد حافظه |
| `mind/<نوع>/<نام>.md` | یک فایل برای هر گره (خودکار از `graph.json` ساخته می‌شود) |
| `notes/` | یادداشت‌های بلند: ایده‌ها و امکان‌سنجی‌شان، خلاصه‌ی گفتگوهای مهم، برنامه‌ها |
| `journal/YYYY/MM/YYYY-MM-DD.md` | دفتر روزانه: چکیده و حال‌وهوای گفتگوهای هر روز (نه متن کامل آن‌ها) |
| `plan/agenda.md`، `plan/items.json` | برنامه، یادآورها و پیشنهادهای قایقران |
| `.graphify/` | گراف عمیق‌تری که graphify هر شب (اختیاری) از حافظه می‌سازد |

> فایل‌های `mind/*.md` از روی `graph.json` بازنویسی می‌شوند؛ برای اصلاح چیزی کافی است به قایقران بگویید، یا در اپ ← دفتر قایقران ← «دانش» آن را ویرایش کنید.
